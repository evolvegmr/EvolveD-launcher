# License and Attribution

## Original project
This repository is based on an existing Android Minecraft launcher codebase that continues to carry upstream provenance from the original launcher ecosystem, including PojavLauncher and its related derivatives.

## Fork relationship
This project was treated as a branded fork and migration of the existing launcher rather than a complete rewrite. The functional launch architecture remains based on the originally working codebase.

## Licensing
The repository continues to include the original project license files and notices. Those files remain authoritative for the source code’s legal status.

## Required notices
- LICENSE
- NOTICE
- third-party component notices and bundled libraries
- attribution for upstream libraries and native components

## What changed for EvolveD
The EvolveD migration updates the user-facing branding, documentation, and optional Firebase configuration while preserving the underlying Minecraft and launcher functionality.

## Important statement
EvolveD Launcher is not claiming to own the entire original codebase. The project remains a fork and derivative of the original launcher ecosystem under its existing licensing and attribution structure.
